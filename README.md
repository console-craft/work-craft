# Work Craft

A Bun workspace for the Work Craft server, terminal UI, and CLI.

## Requirements

- [Bun](https://bun.sh/)

## Setup

```sh
bun install
```

## Workspace

- `packages/server` - server package
- `packages/tui` - terminal UI package
- `packages/cli` - command-line package

## Development

```sh
bun run check
```

To run checks individually, use `bun run lint`, `bun run format:check`, `bun run typecheck`, or `bun run test`.
